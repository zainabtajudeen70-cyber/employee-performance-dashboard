# Employee Performance Dashboard

## 📊 Project Overview

This project is an Employee Performance Dashboard developed to analyze employee performance, salary, attendance, and workforce trends.
## 📊 Dashboard Preview

![Employee Performance Dashboard](ChatGPT%20Image%20Oct%203,%202026,%2012_28_51%20AM.png)
The project demonstrates my ability to collect, clean, transform, analyze, and visualize data using Excel, SQL, Power Query, and Power BI.

## 🎯 Business Objective

The objective of this project is to provide an interactive dashboard that helps management understand:

- Employee performance levels
- Salary distribution
- Attendance patterns
- Workforce trends
- Department-level performance
- Areas that may require management attention

## 🛠️ Tools & Technologies

- **Microsoft Excel** – Data storage and initial data preparation
- **SQL** – Data querying and analysis
- **Power Query** – Data cleaning and transformation
- **Power BI** – Data visualization and dashboard development

## 🔄 Data Preparation

The dataset was prepared through the following steps:

1. Imported the employee dataset into the analysis workflow.
2. Checked for missing and null values.
3. Cleaned and standardized data fields.
4. Reviewed data types and formatting.
5. Used Power Query for data transformation.
6. Used SQL queries to explore and analyze the dataset.
7. Loaded the cleaned data into Power BI.
8. Created calculated measures and visualizations for the dashboard.

## 📈 Dashboard Features

The Power BI dashboard provides an interactive view of employee data through:

- KPI cards
- Employee performance analysis
- Salary analysis
- Attendance analysis
- Department comparisons
- Workforce trend visualizations
- Interactive filters and slicers

## 🔍 Key Analysis Areas

The analysis focuses on:

### Employee Performance
Examining employee performance levels and identifying patterns across the workforce.

### Salary Analysis
Analyzing salary distribution and comparing salary information across employees and departments.

### Attendance
Reviewing attendance patterns to understand workforce participation and potential attendance concerns.

### Workforce Analysis
Exploring employee distribution and trends across relevant workforce categories.

## 💡 Business Value

The dashboard can support management by providing a centralized view of employee information and helping decision-makers identify patterns that may require further investigation.

It demonstrates how raw employee data can be transformed into an interactive business intelligence solution.
